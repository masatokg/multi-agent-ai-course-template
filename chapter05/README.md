# 第5章：評価・ガードレール・HITL

## 📖 この章で学ぶこと

- **評価（Evaluation）**: エージェントの回答品質を測る
- **ガードレール（Guardrails）**: 不適切な入出力を防ぐ仕組み
- **HITL（Human-in-the-Loop）**: 人間がAIの判断を確認する仕組み

## 💡 ポイント解説

### ガードレール（Guardrails）ってなに？

高速道路のガードレール（金属の柵）と同じイメージです。
車が道路の外に飛び出さないように守るように、AIの回答が「常識の範囲外」に
出ないように守ってくれます。

例：
- ❌ 危険な情報（爆発物の作り方など）を聞かれても答えない
- ❌ 個人情報（住所・電話番号など）を勝手に漏らさない
- ❌ 競合他社の悪口を言わない

### HITL（Human-in-the-Loop）ってなに？

「Human-in-the-Loop（ヒューマン・イン・ザ・ループ）」は、「人間を判断ループに組み込む」という意味です。

自動運転車が「このまま直進か、右折か？」と判断に迷ったとき、
ドライバーに確認を求める仕組みに似ています。

AIが高リスクな操作（例：注文の確定、メール送信など）をする前に、
必ず人間が「OK」を押す設計にすることで、ミスを防げます。
