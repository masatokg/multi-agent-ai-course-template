# 第4章：Session・Memory・RAG

## 📖 この章で学ぶこと

- **Session（セッション）**：会話の「履歴」を管理する仕組み
- **Memory（メモリ）**：エージェントが情報を「覚える」仕組み
- **RAG**（検索拡張生成）：外部の知識をAIに「参照」させる仕組み

## 💡 ポイント解説

### Session（セッション）ってなに？

「セッション」は、一回の会話のまとまりのことです。

例えば、コンビニで店員さんに話しかけるとき：
- 最初に「コーヒーください」と言うと、店員さんは「コーヒーの話」だと理解します
- 「砂糖なしで」と続けると、「コーヒーを砂糖なしで」という会話の流れが保たれます

これがセッション管理です。セッションが切れると、最初からやり直しになります。

### Memory（メモリ）ってなに？

AIが会話の内容を「覚えておく」仕組みです。

- **短期記憶**: 今の会話中だけ覚えている（Session）
- **長期記憶**: 次回以降も覚えている（Persistent Memory）

### RAG（検索拡張生成）ってなに？

RAGは「Retrieval-Augmented Generation」の略で、「検索して補強して生成する」という意味です。

図書館の司書（AIエージェント）が「質問を受けたら、まず関連する本を探して、その内容を基に答える」
イメージです。AIの学習データに入っていない最新情報や、社内の独自ドキュメントを参照できます。
