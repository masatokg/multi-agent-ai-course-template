## ⚠️ 重要：保存場所（フォルダパス）についての注意点

トラブルを防ぐために、リポジトリの保存先として **以下の3つの場所は避けてください**。

1. **パスに「日本語（全角文字）」や「スペース」が含まれるフォルダ**
   - × **NG例**: `C:\Users\山田太郎\デスクトップ\AI授業 課題`
   - **理由**: Pythonライブラリやスクリプトが、日本語やスペースを含むパスでエラーを起こすためです。保存先は **`C:\Projects\my-agent-app`** のように半角英数字のみにしてください。

2. **OneDrive や Dropbox などの「クラウド同期フォルダ」内**
   - × **NG例**: `C:\Users\xxx\OneDrive\ドキュメント\...`
   - **理由**: 仮想環境（`.venv`）内の数万個のファイルが常に同期され、動作が非常に重くなったりエラーが発生します。

3. **`C:\Program Files` などの「システム保護フォルダ」**
   - **理由**: アクセス権限エラー（Permission Error）が発生します。

## 🔒 セキュリティに関する注意事項（必ずお読みください）

学生の皆様の安全な学習のため、以下のセキュリティルールを厳守してください。

1. **Google APIキーをソースコード内に直接書き込まないでください**
   - スクリプト内に `api_key = "AIzaxxxx"` のように直接書いてGitHubにプッシュすると、ボットに自動検出され、**キーが無効化されたり不正利用される危険** があります。
   - 本環境では `setup.ps1` が安全にパソコンの「環境変数」として保存しますので、コード内を書き換える必要はありません。

2. **教科書PDFや著作権物を誤ってコミット・公開しないでください**
   - 本リポジトリの `.gitignore` 設定により、`教科書/` フォルダや `.pdf` ファイルは自動的にGit追跡から除外（非表示）されています。設定を解除して公開しないようご注意ください。

3. **`.venv` や個人設定ファイルをGitに含めないでください**
   - 仮想環境（`.venv`）や個人の環境設定（`.env`）は `.gitignore` で保護されています。

## 🚀 環境構築と学習開始の手順

### ステップ 1：GitHubテンプレートから自分専用のリポジトリを作成する

1. ブラウザで以下の **テンプレートリポジトリのページ** にアクセスします：
   - 🔗 **[https://github.com/masatokg/multi-agent-ai-course-template](https://github.com/masatokg/multi-agent-ai-course-template)**
2. ページ右上にある緑色の **「Use this template」** ボタンをクリックし、**「Create a new repository」** を選択します。
3. 以下の項目を設定します：
   - **Repository name**: 自分好みの名前を入力（例: `my-multi-agent-course`）
   - **Access**: `Public` または `Private` を選択（推奨: Private）
4. **「Create repository」** ボタンをクリックします。これで自分専用のリポジトリが作成されます。

---

### ステップ 2：GitHub Desktop でローカルPCにクローンする

1. 作成された自分のリポジトリページで、緑色の **「Code」** ボタンをクリックします。
2. **「Open with GitHub Desktop」** をクリックします。（ブラウザからダイアログが出たら許可してください）
3. GitHub Desktop が起動し、クローン設定画面が表示されます。
4. **Local Path（保存先）** を確認・指定します。
   - ⚠️ **注意**: `C:\Projects\my-multi-agent-course` などの **「日本語なし・スペースなし・OneDrive外」** の場所を指定してください。
5. **「Clone」** ボタンをクリックします。

---

### ステップ 3：GitHub Desktop から VS Code で開く

1. クローンが完了すると、GitHub Desktop の画面に現在のプロジェクトが表示されます。
2. 画面中央の **「Open in Visual Studio Code」**（または `Ctrl` + `Shift` + `A`）をクリックします。
3. VS Code が起動し、プロジェクトが開きます。

---

### ステップ 4：セットアップスクリプト（`setup.ps1`）の実行

1. VS Code 上部のメニューから **[ターミナル] → [新しいターミナル]** を開きます。（または `Ctrl` + `Shift` + `@`）
2. 以下のコマンドを実行して、環境構築スクリプトを起動します：

```powershell
.\setup.ps1
```

3. スクリプトが自動的に以下を行います：
   - Python 3.11+ の確認（未インストールの場合は自動導入）
   - 仮想環境（`.venv`）の作成とライブラリの自動インストール
   - Google AI Studio APIキーの入力画面が表示されたら、取得したキー（`AIza...`）を貼り付けて Enter キーを押す

---

### ステップ 5：章ごとの演習コードの実行

セットアップが完了したら、各章のフォルダに移動してプログラムを実行できます！

```powershell
# 第1章のフォルダへ移動
cd chapter01

# 穴埋め演習用プログラムを実行
python hello_agent.py

# （参考）教科書の完成版サンプルコードを実行する場合
python hello_agent_org.py
```

## ❓ よくあるトラブルと解決方法

### Q. GitHub Desktop で「Open in Visual Studio Code」が表示されない
**A.** VS Code がインストールされていないか、PATHに設定されていない可能性があります。VS Code を公式サイトから再インストールするか、VS Code を直接起動して [ファイル] → [フォルダを開く] からプロジェクトを選択してください。

### Q. PowerShell で「スクリプトの実行が禁止されている」とエラーが出る
**A.** 以下のコマンドを実行して許可を設定してください：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Q. 🚨 429エラー（Too Many Requests / 1分・1日の利用制限）が発生した
**A.** Gemini APIの無料枠制限（429エラー / Resource Exhausted）にかかった場合は、**Google AI Studio で「新しいプロジェクト」を作成し、自分専用の代替APIキーを発行**してください。

#### 代替キーの発行と切り替え手順：
1. ブラウザで [https://aistudio.google.com/](https://aistudio.google.com/) を開きます。
2. 左メニュー「Get API key」➔ **「Create API key in new project」**（新しいプロジェクトでキーを作成）をクリックします。
3. 発行された新しいキー（`AIza...`）をコピーします。
4. VS Code のターミナルで以下のコマンドを実行し、コピーしたキーを入力します：
```powershell
.\change_key.ps1
```
### Q. 🚨 503エラー（Service Unavailable / サーバー高負荷）が発生した
**A.** GoogleのGemini APIサーバー側が混雑している際に503エラーが発生することがあります。

#### 対処法：
Pythonコード内のモデル名を、別の利用可能なモデルに一時的に変更してください。

```python
# 変更前（デフォルト）
root_agent = LlmAgent(model="gemini-2.5-flash", ...)

# 変更例（503エラー回避用モデル）
root_agent = LlmAgent(model="gemini-2.0-flash", ...)  # または "gemini-1.5-flash"
```
モデル名を変更して保存し、再度 `python xxxx_agent.py` を実行してください。
