## 💡 ポイント解説

### A2A（Agent-to-Agent）ってなに？

A2Aは「エージェント同士が会話するためのルール（プロトコル）」です。

例えで言うと、**会社の組織図**のようなものです：
- 営業部（エージェントA）が注文を受ける
- 在庫確認部（エージェントB）に在庫を確認する
- 発送部（エージェントC）に出荷を依頼する

それぞれが専門分野を持ち、A2Aプロトコルで連絡を取り合って、大きなタスクを完成させます。

### マルチエージェントシステムの利点

| 単一エージェント | マルチエージェント |
|---|---|
| 1人で何でもこなす（万能だが限界がある） | 専門家チームで分担（それぞれが得意なことをする） |
| 複雑なタスクで品質が下がりやすい | 各エージェントが専門性を発揮できる |
| 1つのミスが全体に影響する | 相互チェックでミスを発見しやすい |

### このサンプルの構成

```
ユーザー
  ↓（依頼）
コーディネーター（指揮者エージェント）
  ├─→ 分析エージェント（データを分析）
  ├─→ 提案エージェント（改善案を提案）
  └─→ まとめエージェント（報告書を作成）
```
