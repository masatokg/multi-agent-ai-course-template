## 💡 ポイント解説

### プロンプト（指示文）ってなぜ大事なの？

AIに「お腹が空いた」と伝えると、料理のレシピを教えてくれるかもしれません。
でも「今夜、家にある食材（鶏肉・玉ねぎ・じゃがいも）で作れる、20分以内の夕食レシピを3つ教えて」と伝えると、
もっと役立つ答えが返ってきます。

このように、AIへの指示を具体的かつ構造的に書くことを **「Context Engineering（コンテキストエンジニアリング）」** と呼びます。

### サブエージェントってなに？

1つのエージェントにすべてを任せるのではなく、専門家チームのように役割を分けます：

- 🔍 **調査担当エージェント** → 情報を集める
- ✍️ **文章担当エージェント** → わかりやすく文章を書く
- ✅ **チェック担当エージェント** → 内容が正しいか確認する

これにより、複雑なタスクでも高品質な結果が得られます。
