## 💡 ポイント解説

### AIエージェントってなに？

AIエージェントは「自分で考えて行動できるAI」です。

普通のAIは「質問→答え」の繰り返しですが、エージェントは：
1. 目標を理解する
2. どうすれば達成できるか考える
3. ツール（計算機、ウェブ検索など）を使う
4. 結果を確認して次の行動を決める

…という「思考→行動→確認」のサイクルを繰り返します。

### ADKとは？

ADK（Agent Development Kit）は、Googleが開発した「エージェント開発キット」です。
レゴブロックのように、エージェントの部品を組み合わせて作ることができます。
